Why Jellyfin Couldn't Find The Plugin & How It Was Fixed

Here is the exact diagnosis and resolution for your Jellyfin repository:

1. Runs Inside Jellyfin, Not As A Standalone Site

JellyEmu is built to run inside Jellyfin's interface. When you click play on a Flash or HTML5 game in Jellyfin, JellyEmu injects its in-browser players (Templates/flash.html powered by Ruffle WebAssembly and Templates/html5.html) directly into Jellyfin's player modal.

2. Repository URL vs Web Page URL

In Jellyfin (Dashboard > Plugins > Repositories), you must provide the direct raw JSON manifest URL, not the GitHub web page:

https://raw.githubusercontent.com/paullewis1005/JellyEmu-flash-html/main/manifest.json
3. Empty Checksum & GitHub Release 404

Previously, manifest.json had empty checksums ("checksum": "") and pointed to a GitHub release URL that didn't exist yet (404 Not Found), causing Jellyfin to reject the repository or fail download.
✓ Fixed: manifest.json has been cleaned, schema-validated for Jellyfin, and configured with the real MD5 checksum (e07ba322070020cd4cfa6a5b599d7db0).

4. AssemblyName Mismatch in C# Project

JellyEmu.csproj had <AssemblyName>Jellwebgames</AssemblyName> instead of JellyEmu, which caused the compiled binary to be named Jellwebgames.dll while Jellyfin was looking for JellyEmu.dll.
✓ Fixed: Reset AssemblyName and RootNamespace to JellyEmu.

5. Mandatory Jellyfin Dependency: File Transformation Plugin

JellyEmu requires the File Transformation plugin (GUID: 5e87cc92-571a-4d8d-8d98-d2d4147f9f90) installed in Jellyfin to inject the cards and details JavaScript into the web client.

How To Install In Jellyfin (2 Easy Options)

RECOMMENDED

Option 1: Direct Drop-In

The fastest method that bypasses all repository issues completely.

  1. Download JellyEmu_0.10.0.0.zip
  2. Extract the zip files directly into your Jellyfin plugins/JellyEmu/ directory:
    • Linux / Docker: /config/plugins/JellyEmu/
    • Windows: %ProgramData%\Jellyfin\Server\plugins\JellyEmu\
    • macOS: ~/.local/share/jellyfin/plugins/JellyEmu/
  3. Restart your Jellyfin server. Jellyfin will load JellyEmu immediately!
REPOSITORY

Option 2: Add Repo in UI

Install through the Jellyfin Web Admin Dashboard.

  1. In Jellyfin, go to Dashboard > Plugins > Repositories.
  2. Click + (Add Repository).
  3. Repository Name: JellyEmu Flash
  4. Repository URL:
    https://raw.githubusercontent.com/paullewis1005/JellyEmu-flash-html/main/manifest.json
  5. Click Save.
  6. Go to the Catalog tab, click JellyEmu, and install!

Adding Your Games To Jellyfin

1
Create a "Books" Library in Jellyfin

In Jellyfin Dashboard > Libraries > Add Library, choose Books as the Content Type (this is required by Jellyfin's plugin architecture to allow custom metadata downloaders for games).

2
Flash Games (.swf)

Simply drop your .swf files into your ROMs library folder. JellyEmu detects the .swf extension and routes playback through Ruffle WebAssembly inside Jellyfin.

3
HTML5 Games (.html or .zip)

Add individual .html files or packaged .zip files containing an index.html entry point. JellyEmu handles extraction and sandboxed container execution.
